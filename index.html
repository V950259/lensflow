欢迎使用 LensFlow

LensFlow 是一款融合了多模态大模型感知与确定性逻辑引擎的智能视觉助手。

它不只是简单地“看”图，更能深度理解场景，并连接现实世界的服务。


🚀 启动应用 (Streamlit Cloud)

或者在本地运行: streamlit run app.py

✨ 核心亮点

  • 可视化感知引擎: 告别枯燥的 Loading 圈，展示视觉扫描、模型推理、数据解析的全过程。
  • "AI + 规则" 双引擎架构: LensAI (概率层) + LogicEngine (确定层)，确保过敏原预警零容忍。
  • 场景化多轮对话: 支持上下文记忆，图文混合理解，随时追问细节。

📱 场景演示

📅 海报/通知: 提取时间/地点，一键生成 Google Calendar 链接。

💊 食品/药品: 深度成分分析，红色高亮显示潜在过敏原风险。

📖 万物百科: 识别花草、宠物、电子产品，提供详细科普。

🚀 快速开始

1. 环境准备: Python 3.8+

2. 安装依赖: pip install -r requirements.txt

3. 运行应用: streamlit run app.py
